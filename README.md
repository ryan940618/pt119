## 中文
此專案旨在以爬蟲方式記錄屏東縣消防局對外公開之報案紀錄，其狀態以及派遣之分隊的追蹤，以便有需求之民眾進行調閱。  
基於資料來源本身是公開的，惟因沒有紀錄的保存(例如狀態之變化，以及過往日期的資料)，故個人開發此簡易專案進行追蹤。  
  
爬蟲每分鐘更新一次，故更新資料無法精確到秒，亦要考慮Github Pages的更新延遲，實際上看到的資訊會有0~5分鐘的延遲。
本人理解資訊公開是為了便民，若個人此舉被認定為濫用、違法或侵權，再煩請進行告知處理，謝謝。  
  
本專案僅作資訊的統整與歷史留存，**不保證資料的絕對準確性與即時性**，實際情況請以官方公告為準。

## English  

This project aims to collect and archive 119 reports released by the Pingtung CountyFire Department, tracking their status and the dispatched fire brigade units, for the historical record and information accessible to public and to people who is in need.  
Despite the data is publicly available, the original source does not retain historical records, such as changes in incident status or reports from previous dates. To address this limitation, this simple project is built up to track, organize, and preserve the data over time.  
  
The scraper updates the data once every minute, so the timestamp of updated data only accurate to minute, the compile delay of Github Pages should also be considered, the actual delay will be approximately 0 to 5 minutes.  
I understand that the original source site is built for serving public interest. If this project is deemed to constitute misuse, violation of laws, or an infringement of rights, please feel free to contact me so that I can address the matter accordingly. Thank you.  
  
**This project does not guarantee the absolute accuracy or real-time availability of the data.** For actual emergencies, incident details, and exact accurate dispatch information, please refer to the source or official announcements and information released by the authorities.
